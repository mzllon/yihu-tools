## 一、呼出面板（tools/yihu-panel）

单二进制双角色：无参 = 常驻守护进程，`toggle/show/hide/quit/status/files` = 薄 CLI。

### 呼出与窗口

| 功能 | 状态 | 说明 |
|---|---|---|
| 全局热键呼出 | ✅ | Alt+Space（自动解除 GNOME 内置占用并重抓 gsd） |
| 暖 toggle 性能 | ✅ | ~10ms，红线 <100ms；待命 PSS ~20MB |
| 呼出路径零 IO | ✅ | 应用/历史/主题判定全在启动时完成 |
| 隐藏待命零进程 | ✅ | 非常驻插件收起整组 SIGKILL |
| 失焦自动隐藏 | ✅ | 含焦点守卫（未获得焦点不误隐） |
| 窗口定位 | ✅ | Shell 扩展「上 1/4 居中」+ Where 轮询闭环 + 淡入（BUG-002 闭环） |
| 高度自适应 | ✅ | 内容贴合，超 520 滚动 |
| 主题跟随系统 | ✅ | 实时监听 color-scheme 变化 |
| DBus 服务 | ✅ | Toggle/Show/Hide/Quit/SelectFiles/Visible |
| 单实例保护 | ✅ | 总线名占用即静默退出 |
| 开机自启 | ✅ | 中心设置页管理（systemd user 单元） |

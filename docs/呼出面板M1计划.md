# 呼出面板 M1 开发计划（骨架）

> 依据：[呼出面板调研](呼出面板调研.md) §4。状态：**已完成（2026-09-16）**。
> 底线：隐藏待命、cairo 渲染、show 路径零 IO、暖 toggle < 100 ms。

## 实测结果（release 构建，Ubuntu 24.04 / Wayland）

| 指标 | 门槛 | 实测 | 结论 |
|---|---|---|---|
| 待命 RSS | ≤ 40 MB（原） | ~71 MB | **口径修正**：本机空 GTK4 进程共享库映射即 ~45 MB，RSS 门槛按调研期社区数字设定不成立；改以 PSS 为物理占用口径 |
| 待命 PSS | —（新口径 ≤ 30 MB） | **~25 MB** | ✅ 优于中心（31 MB） |
| 暖 toggle 全程 | < 100 ms | **~10 ms** | ✅ 含薄 CLI 进程 + DBus 往返 + 主循环消费 |
| 1 万条过滤 | < 16 ms/次 | **0.4–3.4 ms** | ✅ nucleo 双线程；`YIHU_PANEL_BENCH=1` 可复现 |
| show 路径 IO | 0 | 0 | ✅ 窗口/列表/主题判定启动时完成 |
| 打包测试 | 全绿 | PASS | ✅ 含旧版（无 panel）升级场景；真机 dry-run 通过 |

过程记录：

- **快捷键「注册成功但按下无反应」真机排障（2026-09-16，已闭环进代码）**。
  现象：gsettings 注册成功、`yihu-panel toggle` 手动可用，但按 Alt+Space 无反应。
  根因有两层：① GNOME 内置「激活窗口菜单」默认即 `<Alt>space`，mutter
  先行拦截，自定义快捷键根本收不到；② 解除内置键后 gsd-media-keys
  **不会自动重试按键抓取**，需要重新扫描 custom-keybindings 列表才会生效
  （重启 gsd 服务被 RefuseManualStop 拒绝，「摘除 → 写回」列表等效且安全）。
  解决：`panel::register_hotkey` 现在注册前自动检测并解除内置占用，
  再以「摘除 → 写回」强制 gsd 重新抓取；中心页提示同步更新。
  手动恢复内置键：`gsettings reset org.gnome.desktop.wm.keybindings activate-window-menu`。
- 演示数据生成初版 `for i in 0..` 为无限区间，1 万条全部落在第一组词；
  修复为 `0..1000`，并以 `YIHU_PANEL_BENCH` 探针验证各词组分布与模糊命中。
- 真机 dry-run 暴露并修正了机器侧遗留状态（与本仓库无关）：yihu 相关
  desktop/图标/扩展/systemd 单元文件为组可写权限（安装器 `safe()` 拒绝）、
  autodark 单元仍是早期品牌文本且 ExecStart 指向已删除的旧
  checkout。均已修正。
- 升级路径：安装器 dest 目录检查从「精确集合」放宽为「子集 + 所有权标记」，
  旧版（无 yihu-panel）安装可正常升级；未知多余文件仍然中止。
  test-package.py 增加对应升级场景。

## 决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 默认热键 | `Alt+Space`（用户已确认） | uTools 默认；GNOME 无占用、不撞输入法；中心页可改 |
| M1 含打包链路 | 是（用户已确认） | 交付即可安装；reinstall.sh 6 处检查点 + test 夹具同步 |
| panel UI 栈 | GTK4-only，无 libadwaita | 全自绘浮动卡片；深浅色经 `autodark::current_scheme()` + CSS class；省一份共享库 |
| DBus 模式 | zbus（独立 crate 版本入锁） | CLI 用 blocking，daemon 服务对象在 zbus 线程回调，经 mpsc + 主循环轮询进 GTK（仿 tray.rs 惯例） |
| 占位 UI | ListView+Factory + 1 万静态演示条目 + nucleo 过滤 | 把「万条过滤单帧 <16ms」验收提前到 M1 兑现 |
| 图标 | 复用 `tools.yihu.desktop`，不新增图标资产 | 避免 gen_icon/打包/安装器图标链路联动改动 |

## 功能清单

- **F1 daemon**：`tools/yihu-panel` 单二进制双角色——无参数 = GTK4 隐藏待命窗口；
  `toggle/show/hide/quit/status` = 薄 CLI；main 开头 `GSK_RENDERER=cairo`。
- **F2 窗口**：720×480 浮动卡片；Entry 常驻焦点；toggle = present+grab_focus；
  ESC / 失焦隐藏（防递归）；ListView+Factory；演示数据 idle 生成（show 零 IO）。
- **F3 zbus**：`tools.yihu.Panel`（/tools/yihu/Panel）方法 Toggle/Show/Hide/Quit、
  属性 Visible；CLI 兜底：bus 名不存在 → spawn 同目录 daemon → 轮询等待（≤3s）。
- **F4 yihu-core `panel.rs`**：`panel.conf`（kv）；gsettings 自定义快捷键
  **合并注册**（路径 `…/customYihuPanel/`，解析失败不写入）与移除；
  `merge_keybinding_list()` 纯函数单测；`proc_stats` 上移为
  `yihu_core::find_process_stats`（page_settings 改调用）。
- **F5 中心「呼出面板」页** `page_panel.rs`：状态卡（RSS/PSS + 启动/退出）、
  热键卡（预设下拉 Alt+Space/Alt+Z/Alt+R/Ctrl+Space + 注册/移除，后台线程执行）、
  自启开关（`yihu-panel.desktop`）、Wayland 说明卡、5s 刷新。
- **F6 打包**：build-package.sh（install + sha256 清单）、reinstall.sh
  （required/ELF/dest 集合/pgrep+allowed/desktop() 面板分支）、test-package.py 夹具。
- **F7 文档**：README 能力表/目录结构/新增能力步骤/实测表加行；调研文档标 M1 状态。

## 风险与备选

- cairo 帧率无公开基准 → S2 真机实测，不足局部切 ngl 并记录；
- 焦点抢占边缘情况（Ulauncher #1128 同类）→ M1 接受并写入说明卡；
- zbus 与 mpris-server 内部 zbus 版本共存 → 各自锁定入 Cargo.lock；
- gsettings 列表损坏 → 解析失败报错返回，不写入。

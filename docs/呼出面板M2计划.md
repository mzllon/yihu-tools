# 呼出面板 M2 计划（真实提供者）

> 依据：[呼出面板调研](呼出面板调研.md) §4。状态：**已完成（2026-09-18，
> 含用户实测驱动的默认集/位置/高度三轮 UI 迭代）**。
> 目标：演示数据 → 真实搜索：应用启动、内置能力、算式计算。
> 性能红线不回退：待命 PSS ≤ 30 MB、暖 toggle < 100 ms、show 路径零 IO。

## 交付内容

- **F1 条目真实化**：列表项携带 `kind/payload/icon_spec`（"app" / "cap" / "calc"），
  激活分发真实动作后自动隐藏；行首换 `gtk::Image::set_from_gicon` 真图标
  （ThemedIcon 名 / FileIcon 路径 / 兜底 executable-symbolic）。
- **F2 应用提供者**：启动时 `gio::AppInfo::all()` + `should_show()` 过滤，
  显示名进 nucleo，激活 `DesktopAppInfo::launch()`；运行期新装应用需重启面板（M3 刷新）。
- **F3 能力提供者 v0**（进程内）：切换深色/浅色（`autodark::set_scheme`，后台线程）、
  打开一呼中心、打开广播页/主题切换页（spawn `yihu --page …`）。
- **F4 计算器**：`calc.rs` 递归下降（`+ - * / % ^`、括号、一元正负号、右结合幂，
  无外部 crate）；可解析时置顶「= 结果」行，回车复制（面板持焦时 Wayland 可写剪贴板）。
- **F5 中心 `--page` 深链**：`HANDLES_COMMAND_LINE` + `add_main_option` +
  `connect_command_line`；build 移入命令线路径，UI 句柄存 thread_local
  （GTK 对象非 Send，不能进 static）。
- **F6 历史/默认集**：`panel_history.json`（mt-core `History`），激活后台落盘；
  空输入 = 能力置顶 → 最近使用应用（次数/时间序）→ 其余应用。
- **F7** 空态「无匹配」行；移除 M1 演示数据。

## 实测结果（release，Ubuntu 24.04 / Wayland）

| 指标 | 门槛 | 实测 | 结论 |
|---|---|---|---|
| 待命 RSS / PSS | PSS ≤ 30 MB | **~43 MB / ~12.5 MB** | ✅ 远优于门槛（移除演示数据后工作集大幅缩小） |
| 暖 toggle 全程 | < 100 ms | **~10 ms** | ✅ |
| show 路径 IO | 0 | 0 | ✅ 枚举/历史均在启动时 |
| 应用枚举 | — | ~9 ms（61 可见应用，一次性） | ✅ |
| 打包测试 | 全绿 | PASS | ✅ |
| 默认集形态 | 分组限量 | 「最近」胶囊 4 + 「快捷能力」胶囊 5 | ✅ 用户三轮迭代后定稿 |
| 屏幕位置 | — | 上部居中再上移 100px、置顶 | ✅ 定位扩展 + 参数化偏移 |

真机回归：中心 `--page radio` 冷启动正常；二次 `--page autodark` 立即转发
（exit=0）并切换页面置前；自启 desktop（无参 Exec）路径不受
HANDLES_COMMAND_LINE 影响（命令线路径兜底建 UI）。

## 过程记录

- **屏幕位置（参数化偏移）**：摆放偏移走 panel.conf `place_offset_up`
  （默认 100px，呼出时读取），`PlaceTop(offset_up)` 传给扩展，旧扩展回退
  无参调用；中心热键注册改 load-modify-save 保留该配置。
- **屏幕位置**：mutter 对普通窗口的摆放不保证居中（避让/级联），且 Wayland
  隐藏后重新 present 不会重新摆放、多次调高以左上角锚定导致漂移到角落。
  解决：① 呼出时销毁重建窗口（新映射触发重新摆放，共享状态在 Deps 跨呼出
  保持，重建仅控件成本，待命期不再持有窗口）；② 新增可选 GNOME Shell 扩展
  `yihu-panel-placer@tools.yihu`（约 2KB，DBus tools.yihu.ShellPlacer/PlaceTop），
  面板呼出时通知扩展移到「水平居中、垂直上 1/4」并置顶；中心页一键安装
  （内嵌源码写入用户扩展目录 + 合并 enabled-extensions），新装需重新登录一次。
- **首帧透明**：扩展摆放天然晚于首帧，改为窗口全透明映射、摆放完成后
  淡入（~150ms），定位竞争窗口期对用户不可见。
- **失焦误隐藏**：快捷键触发的映射可能拿不到焦点（防焦点抢占），
  is-active=false 被误判为点击别处导致面板一闪即逝；
  改为仅对「曾拿到焦点」的窗口启用失焦隐藏。
- **回车不生效**：焦点常驻搜索框，回车到不了列表（M1 起靠双击未暴露）；
  搜索框 connect_activate 激活当前选中项，并打开单击即激活。
- **默认集三轮迭代（用户实测驱动）**：① A+B 组合定稿分组骨架；② 精简为
  两行胶囊（「最近」4 个 + 「快捷能力」5 个，移除常用应用分区与百行平铺）；
  ③ 高度自适应：估算行高偏差导致误出滚动条，改用
  `propagate-natural-height + max-content-height(520)` 原生语义——
  内容不超高无滚动条、超高才滚。
- 计算器优先级 bug：初版文法把一元负号放在幂之上，`-2^2` 得 4；
  修正为「指数侧才允许一元符号」的文法（`-2^2 = -4`、`2^-3 = 0.125`），
  并补充 `(1+2` 缺右括号拒绝等测试。
- 真机深链一度失败，根因是**旧版中心进程仍持有总线名**（跑在开发目录上，
  不认识命令行转发）——升级后需重启中心。此为运维现象，非代码缺陷。
- gio 0.20 的 `launch()` 签名带 AppLaunchContext 参数；
  `VariantDict::lookup` 无 depth 参数——以实际 API 为准修正。
- 中心写自启 desktop 显式 0644（umask 002 系统上 664 会被安装器拒绝）。

- 中心页补充位置偏移调节控件（当前改 panel.conf 即时生效）；
- 扩展调试仪表（journal 日志 + Where 查询）视需要在 M3 移除或保留。

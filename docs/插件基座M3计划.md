# 插件基座 M3 计划与实施记录

> 依据：[插件基座调研](插件基座调研.md)。状态：**已完成（2026-09-18）**。
> 宗旨：性能高、资源占用率低——插件不用时零进程零内存。

## 协议 v0（stdio 行式 JSON，主版本 1）

```
宿主→插件  {"type":"init","api":1,"data_dir":"…"}
宿主→插件  {"type":"query","id":N,"text":"…"}
插件→宿主  {"type":"ready"}                                        # 可选
插件→宿主  {"type":"results","query_id":N,
            "items":[{title,subtitle,icon,payload}]}
宿主→插件  {"type":"activate","id":N,"payload":"…"}
```

- 会话：面板呼出拉起全部启用插件（process_group(0)），收起整组 SIGKILL；
- 结果幂等：query_id 过期丢弃；结果到达置 dirty，复用既有 30ms tick 合流；
- v0 激活语义：宿主复制 payload 到剪贴板 + 转发 activate（Wayland 下
  插件进程自行操作剪贴板不可靠）；
- 超时/崩溃：无响应结果自然缺席；滑动窗口 4 次/5 分钟连崩则本运行期
  禁用（vscode-languageclient 同款），中心页可手动恢复。

## 交付内容

- **yihu-core `plugins.rs`**：manifest（TOML）解析与校验（id 字符集、
  api range 匹配、entry 非空且不越目录）、注册表与状态路径、
  `list_installed` / `install_from_dir`（校验+递归复制+权限）/
  `remove_plugin`；单测 5 个。
- **面板 `sessions.rs`**：PluginMgr——会话拉起（process_group(0)）、
  init/query 广播、读线程 mpsc 回传、stale 丢弃、退出计数窗口、
  kill_all；跨呼出保持失败历史。
- **面板 `providers.rs`**：内置能力迁为进程内系统插件形态（查询子串
  匹配 + activate），默认集「快捷能力」胶囊不受影响。
- **面板合流**：结果顺序 = 计算行 → 应用（nucleo）→ 内置能力 → 插件；
  `kind:"plugin"`（payload = `<插件id>|<原始payload>`）。
- **中心「插件」页**：说明卡（协议/权限/隔离）、本地目录安装
  （校验+递归复制+0644/755 权限）、列表（名称/版本/权限/入口/启停
  Switch/移除）、坏 manifest 错误明示。
- **示例插件 ×3**：ts-convert（Rust，时间戳↔日期）、passgen（Python，
  密码生成）、内置主题=系统插件。`scripts/install-example-plugins.sh`
  一键装入注册表。

## 实测结果（release，Ubuntu 24.04 / Wayland / GNOME 50.1）

| 指标 | 门槛 | 实测 | 结论 |
|---|---|---|---|
| 面板待命 PSS（无插件会话） | 与 M2 持平 | ~20.6 MB（含插件会话运行时） | ✅ |
| 收起后插件进程 | 0 | 0（精确名匹配） | ✅ |
| Rust 插件进程 PSS | ≤ 10 MB | **0.5 MB** | ✅ |
| 暖 toggle 全程 | < 100 ms | ~10–30 ms | ✅ |
| 插件协议端到端 | init→ready / query→results | ✅（管道冒烟+真机会话） | ✅ |
| 打包测试 | 全绿 | PASS（6/6 套件） | ✅ |

## 过程记录

- manifest 初版误写成 JSON 语法存为 .toml，被解析校验当场拦下
  （协议校验第一案），已改 TOML 并修正示例；
- 外部进程协议选型依据调研：Rust 插件 spawn 1–2ms/RSS 0.3–2MB、
  JSON 1KB 2–5µs、stdio 小消息快于 UDS ~30%、Node 按需判死；
- `process_group(0)` + 组级 SIGKILL 确保插件子进程不留孤儿；
- 崩溃禁用为本运行期粒度（重启面板即恢复），持久禁用待议。

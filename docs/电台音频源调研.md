## 1. 全球电台数据库

**radio-browser.info** — <https://www.radio-browser.info>
目前最大的全球电台数据库，收录 **4 万+ 个电台直播流地址**；无需注册、可直接
搜索试听。Transistor、RadioDroid、Shortwave 等开源播放器均内置其搜索。
开放 REST API，社区维护（客户端按命中率投票排序）。
局限：面向全球用户，**国内电台收录有限**——国内台以下面聚合平台为准。

## 2. 国内广播聚合平台（原文收录）

| 平台 | 网页 | 收录与特点 |
|---|---|---|
| **蜻蜓 FM** | <https://www.qingting.fm> | 国内台最全：**3000+ 电台**，央广到省市台基本都有；7 天回听、分类找台、定时关闭。第三方 App 听蜻蜓需自行找直播流（.m3u8），社区有开源解析项目 |
| **云听** | <https://www.radio.cn> | 央广/总台**官方** App：收录央视、央广全部频率；无广告、官方源稳定、支持回听 |
| **喜马拉雅** | <https://www.ximalaya.com> | 以播客/有声书为主，也有直播频道 |

## 3. 官方直连流与播放列表（原文收录）

**央广 CDN 固定格式**：`ngcdn004.cnr.cn/live/{频道缩写}/index.m3u8`
（缩写 = 频率名拼音首字母）。已公开的五条：

| 电台 | 直播流 |
|---|---|
| 中国之声 | `http://ngcdn004.cnr.cn/live/dszs/index.m3u8` |
| 经济之声 | `http://ngcdn004.cnr.cn/live/jjzs/index.m3u8` |
| 音乐之声 | `http://ngcdn004.cnr.cn/live/yyzs/index.m3u8` |
| 中华之声 | `http://ngcdn004.cnr.cn/live/zhzs/index.m3u8` |
| 文艺之声 | `http://ngcdn004.cnr.cn/live/wyzs/index.m3u8` |

**M3U / PLS 播放列表**：GitHub 开源项目（搜 "radio m3u" / "iptv radio"）、
IPTV 频道列表常含 radio 分类、自建收集。

```m3u
#EXTM3U
#EXTINF:-1,中国之声
http://ngcdn004.cnr.cn/live/dszs/index.m3u8
```

```ini
[playlist]
NumberOfEntries=1
File1=http://ngcdn004.cnr.cn/live/dszs/index.m3u8
Title1=中国之声
```

**自行找流的方法**（原文）：F12 → Network 搜 `.m3u8`/`.mp3`；GitHub 搜
"radio m3u china" / "qingting m3u8" / "cnr live stream"；官方已知地址直用。

## 4. 应用到一呼电台插件（本仓库判断，非原文）

- **v1 主源 = 蜻蜓 FM**（qtfm API 契约见蜻蜓FM-API调研.md），覆盖「3000+ 全」
  的核心诉求，无鉴权、可直接拼 HLS 流。
- **央广五条直连流**：与蜻蜓频道重复但**不依赖蜻蜓**（官方 CDN）——候选作
  「央广频道兜底源」：蜻蜓某央广台播放失败时可切换直连流。实现成本低
  （5 个静态映射），W6 不做、记入后续。
- **radio-browser.info**：国际台扩展候选（W6 之后，有真实需求再做）；
  其 API 是开放 REST，接入模式与 qtfm 类似。
- **M3U 导入**：用户自定义源入口候选（「我的电台」自添加流地址），与收藏
  功能天然合并——收藏可直接存外部流 URL。
